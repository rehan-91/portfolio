## 📦 Run Locally

Clone the repository

```bash
git clone https://github.com/rehan-91/portfolio.git
```

Go into the project directory

```bash
cd portfolio
```

Install dependencies

```bash
pnpm install
```

Run the development server

```bash
pnpm dev
```

Open your browser and visit:

```
http://localhost:3000
```
